{/* # Getting Started with Trackpilots API */}

Trackpilots APIs are designed to help organizations integrate employee activity, productivity, and compliance data directly into their internal systems.

<Callout icon="key" color="#22C55E" iconType="regular">API access is available. Create your key from Developer Tools → API Keys.</Callout>

## Step 1: Create an API key

1. Open **Developer Tools → API Keys** in your Trackpilots dashboard. Direct link: [app.trackpilots.com/developer-tools/api-keys](https://app.trackpilots.com/developer-tools/api-keys)
2. Select **Create API Key**, give it a name, and save.
3. Copy the key and store it securely. See [API Keys](/docs/developer-tools/api-keys) for details.

<Note>
You need a Trackpilots account with **Full Access**. Each organisation can keep up to 5 API keys.
</Note>

## Step 2: Authenticate your requests

Send your API key as a Bearer token in the `Authorization` header:

```http
Authorization: Bearer YOUR_API_KEY
```

## What you can do

With the Trackpilots API you can:

- Authenticate using API keys
- Access user, activity, and productivity data
- Build custom dashboards and internal reports
- Receive real-time events via webhooks
- Integrate Trackpilots with HR, payroll, and BI tools

## Who is this for?

- Engineering teams building internal integrations
- Organizations requiring advanced reporting
- Enterprise customers needing customized API access
